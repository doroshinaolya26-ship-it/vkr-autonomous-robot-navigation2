# Отчёт по экспериментам

В проекте реализовано сравнение двух подходов:
- базовый глобальный планировщик A*;
- гибридный алгоритм (A* + локальная коррекция + replanning).

## Сценарии
1. **Scenario 1** — пустая статическая среда.
2. **Scenario 2** — статическая среда с препятствиями.
3. **Scenario 3** — динамическая среда: во время движения на пути появляется препятствие.

## Выходные артефакты
После запуска `python src/simulation.py` автоматически формируются:
- изображения траекторий в `results/`;
- таблица метрик `results/metrics.csv`.

## Что анализируется
- длина пути;
- время выполнения;
- количество replans;
- достигнута ли цель.
