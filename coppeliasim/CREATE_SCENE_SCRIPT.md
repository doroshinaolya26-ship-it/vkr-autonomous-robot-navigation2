# Автоматическое создание демонстрационной сцены CoppeliaSim

В репозитории нет готового бинарного файла сцены CoppeliaSim с расширением `.ttt` или `.ttm`. Такие файлы обычно создаются и сохраняются из установленного CoppeliaSim. Поэтому в проект добавлен Lua-скрипт `coppeliasim/create_demo_scene.lua`, который автоматически формирует максимально возможную заготовку сцены из примитивов.

Скрипт совместим с актуальными версиями CoppeliaSim Edu: он не использует `sim.drawing_text`, потому что эта константа может отсутствовать. Подписи реализованы через цветные 3D-маркеры и dummy-объекты с понятными именами, а русский список компонентов дополнительно выводится в консоль CoppeliaSim.

## Что создает скрипт

Скрипт `create_demo_scene.lua` добавляет в текущую сцену:

- плоскость движения;
- корпус мобильного робота с главным объектом `robot`;
- колесную базу;
- левое и правое приводные колеса;
- лидар / дальномерный сенсор;
- ультразвуковые и инфракрасные датчики расстояния;
- IMU для положения и ориентации;
- маркеры энкодеров колес;
- контактный датчик / bumper;
- локальную карту / occupancy grid;
- статические препятствия;
- стартовую и целевую точки;
- маршрут движения A*;
- цветные таблички-маркеры и dummy-объекты компонентов;
- камеру `vkr_screenshot_camera` для подготовки скриншота, если создание камеры доступно в используемой версии API.

## Вариант 1: запуск через CoppeliaSim Sandbox Lua

1. Откройте CoppeliaSim Edu.
2. Создайте новую пустую сцену: `File > New scene`.
3. Откройте окно **Sandbox script**. В разных версиях CoppeliaSim оно может находиться в меню `Tools`, `Add-ons`, `Modules` или в панели script editor.
4. В Sandbox Lua выполните команду `dofile`, указав абсолютный путь к скрипту. Пример для Linux:

```lua
dofile('/home/user/vkr-autonomous-robot-navigation2/coppeliasim/create_demo_scene.lua')
```

Пример для Windows: используйте прямые слэши `/` или экранируйте обратные слэши `\\`:

```lua
dofile('C:/Users/User/vkr-autonomous-robot-navigation2/coppeliasim/create_demo_scene.lua')
```

5. После выполнения в сцене появятся объекты с префиксом `vkr_`, а главный объект робота будет называться `robot`.
6. Проверьте консоль CoppeliaSim: скрипт напечатает список русских подписей и соответствующих dummy-объектов.
7. Сохраните сцену через `File > Save scene as...`, например под именем `coppeliasim_robot_navigation_demo.ttt`.

## Вариант 2: запуск из встроенного Lua-редактора

1. Откройте CoppeliaSim Edu и создайте пустую сцену.
2. Создайте новый sandbox/add-on Lua script или откройте встроенный редактор Lua-скриптов.
3. Скопируйте содержимое файла `coppeliasim/create_demo_scene.lua` в редактор.
4. Запустите скрипт.
5. Сохраните созданную сцену как `.ttt`.

## Запуск Python-контроллера после создания сцены

1. Запустите симуляцию в CoppeliaSim.
2. Из корня репозитория выполните:

```bash
python coppeliasim/coppelia_controller.py
```

Python-контроллер ищет объект `/robot`, поэтому важно не переименовывать главный корпус робота после создания сцены.

## Как получить скриншот для ВКР

1. Выберите камеру `vkr_screenshot_camera` или настройте вид сверху/под углом вручную.
2. Убедитесь, что видны мобильный робот, сенсорные компоненты, препятствия, старт, цель и маршрут.
3. В дереве сцены найдите dummy-объекты с префиксом `vkr_label_`: они играют роль подписей компонентов, если текстовые drawing object недоступны.
4. Сделайте скриншот окна CoppeliaSim.
5. При необходимости сохраните сцену в `.ttt`, чтобы повторно открыть ее без повторного запуска Lua-скрипта.

## Примечание по кодировке

Файл `create_demo_scene.lua` сохранен в UTF-8. Если в консоли CoppeliaSim русские строки отображаются как `РђРІ...`, это проблема кодировки окна вывода, а не логики сцены. Визуальные объекты и dummy-объекты используют ASCII-имена, поэтому остаются читаемыми в дереве сцены на любой локали. Для русских подписей используйте соответствие, напечатанное в консоли, или таблицу из `docs/ROBOT_COMPONENTS_SPECIFICATION.md`.

## Примечание по совместимости API

Скрипт сначала пытается использовать `sim.createPrimitiveShape`. Если в конкретной версии API эта функция отсутствует или имеет несовместимую сигнатуру, скрипт автоматически использует `sim.createPureShape` как fallback. `sim.drawing_text` намеренно не используется.
