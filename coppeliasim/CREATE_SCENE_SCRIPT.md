# Автоматическое создание демонстрационной сцены CoppeliaSim

В репозитории нет готового бинарного файла сцены CoppeliaSim с расширением `.ttt` или `.ttm`. Такие файлы обычно создаются и сохраняются из установленного CoppeliaSim, поэтому в проект добавлен Lua-скрипт `coppeliasim/create_demo_scene.lua`, который автоматически формирует максимально возможную заготовку сцены из примитивов.

## Что создает скрипт

Скрипт `create_demo_scene.lua` добавляет в текущую сцену:

- плоскость движения;
- корпус мобильного робота с главным объектом `robot`;
- колесную базу;
- левое и правое приводные колеса;
- лидар / дальномерный сенсор;
- ультразвуковые и инфракрасные датчики расстояния;
- IMU для положения и ориентации;
- маркеры энкодеров колес;
- контактный датчик / bumper;
- локальную карту / occupancy grid;
- статические препятствия;
- стартовую и целевую точки;
- маршрут движения A*;
- визуальные подписи компонентов на русском языке;
- камеру `vkr_screenshot_camera` для подготовки скриншота.

## Как запустить скрипт в CoppeliaSim

1. Откройте CoppeliaSim.
2. Создайте новую пустую сцену или откройте существующую сцену, в которую нужно добавить демонстрационные объекты.
3. Откройте встроенный редактор Lua-скриптов или консоль выполнения скриптов CoppeliaSim.
4. Загрузите содержимое файла:

```text
coppeliasim/create_demo_scene.lua
```

5. Выполните скрипт. После выполнения в сцене появятся объекты с префиксом `vkr_`, а главный объект робота будет называться `robot`.
6. Сохраните сцену через `File > Save scene as...`, например под именем `coppeliasim_robot_navigation_demo.ttt`.
7. Запустите симуляцию и из корня репозитория выполните Python-контроллер:

```bash
python coppeliasim/coppelia_controller.py
```

## Как получить скриншот для ВКР

1. Выберите камеру `vkr_screenshot_camera` или настройте вид сверху/под углом вручную.
2. Убедитесь, что видны мобильный робот, сенсорные компоненты, препятствия, старт, цель и маршрут.
3. Сделайте скриншот окна CoppeliaSim.
4. При необходимости сохраните сцену в `.ttt`, чтобы повторно открыть ее без повторного запуска Lua-скрипта.

## Примечание по совместимости

Lua API CoppeliaSim может немного отличаться между версиями. Если отдельные подписи или примитивы не создались, используйте `coppeliasim/SCENE_SETUP.md` как ручную инструкцию и проверьте, что главный объект робота называется `robot`. Python-контроллер ищет именно объект `/robot`.
