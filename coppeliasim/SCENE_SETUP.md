# Настройка сцены CoppeliaSim

## Пошаговая инструкция
1. Откройте CoppeliaSim.
2. Добавьте модель **PioneerP3DX** на сцену.
3. Выберите главный объект модели и переименуйте его в `robot` (маленькими буквами), чтобы путь объекта был `/robot`.
4. Убедитесь, что включен ZeroMQ Remote API (status: **ZeroMQ Remote API server running**).
5. Запустите симуляцию в CoppeliaSim (кнопка Play).
6. Откройте Windows CMD в корне проекта.
7. Выполните команду:

```cmd
python coppeliasim\coppelia_controller.py
```

## Ожидаемое поведение
- На сцене создаются кубы статических препятствий (`obstacle_*`).
- Создаются маркеры маршрута (`point_*`).
- Во время движения появляется динамическое препятствие (`dynamic_obstacle_*`).
- Робот `/robot` визуально движется к точкам маршрута с локальным перестроением.
- Метрики записываются в `results/coppelia_metrics.txt`.
