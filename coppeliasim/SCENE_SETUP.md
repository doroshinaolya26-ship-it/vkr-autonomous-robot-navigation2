# Настройка сцены CoppeliaSim

## Пошаговая инструкция
1. Откройте CoppeliaSim.
2. Добавьте модель PioneerP3DX.
3. Переименуйте главный объект модели в `robot`.
4. Нажмите Play.
5. Запустите из Windows CMD:

```cmd
python coppeliasim\coppelia_controller.py
```

## Проверка
- На сцене должны появиться красные препятствия, зелёные точки маршрута и синее динамическое препятствие.
- Робот `/robot` должен быть виден на полу и плавно двигаться по маршруту.
- Метрики сохраняются в `results/coppelia_metrics.txt`.

## Рекомендация для записи видео
- Используйте формат MP4/MPEG-4 part 2 или AVI/MPEG-4 part 2.

- Перед повторным запуском желательно остановить симуляцию и нажать Play заново.
