# Подготовка демонстрационной сцены CoppeliaSim для ВКР

Данный файл описывает ручную сборку сцены CoppeliaSim для демонстрации автономного мобильного робота, сенсорных компонентов локального восприятия и движения по маршруту, рассчитанному алгоритмом A*. Автоматически сформировать корректный бинарный файл `.ttt`/`.ttm` без установленного CoppeliaSim в репозитории невозможно, поэтому ниже приведена воспроизводимая инструкция по созданию сцены вручную.

## 1. Создание рабочей области

1. Откройте CoppeliaSim и создайте новую сцену.
2. Добавьте плоскость (`Add > Primitive shape > Plane`) и задайте ей размер, например `6 x 6 м`.
3. Назовите плоскость `floor`.
4. Включите отображение сетки, чтобы стартовая и целевая точки были удобны для визуального контроля.

## 2. Мобильный робот

1. Добавьте простую модель мобильного робота из библиотеки CoppeliaSim либо соберите модель из примитивов.
2. Если готовой модели нет, создайте корпус из куба (`Cuboid`) размером примерно `0.45 x 0.30 x 0.18 м` и назовите его `robot`.
3. Добавьте колесную базу как нижнюю часть корпуса или отдельный объект `wheel_base`.
4. Добавьте левое и правое приводные колеса (`left_wheel`, `right_wheel`) в виде цилиндров по бокам корпуса.
5. Для демонстрации движения Python-контроллер должен находить главный объект по имени `robot`. Имя должно быть задано ровно как `robot`.

## 3. Сенсорные компоненты локального восприятия

Разместите на роботе визуальные элементы, которые будут обозначать сенсорные компоненты. Если физическая модель датчика не нужна, допустимо использовать небольшие примитивы с понятными именами.

| Компонент | Рекомендуемое имя в сцене | Как визуально обозначить |
| --- | --- | --- |
| Лидар / дальномерный сенсор | `lidar_sensor` | Небольшой цилиндр на верхней панели корпуса |
| Передний ультразвуковой датчик | `front_range_sensor` | Малый куб/цилиндр на передней грани |
| Левый датчик расстояния | `left_range_sensor` | Малый куб слева на корпусе |
| Правый датчик расстояния | `right_range_sensor` | Малый куб справа на корпусе |
| IMU | `imu_sensor` | Плоский прямоугольник или маленький куб в центре корпуса |
| Энкодер левого колеса | `left_wheel_encoder` | Маркер рядом с левым колесом |
| Энкодер правого колеса | `right_wheel_encoder` | Маркер рядом с правым колесом |
| Контактный датчик / bumper | `contact_sensor` | Узкая полоса на передней части корпуса |
| Локальная карта / occupancy grid | `local_occupancy_grid` | Полупрозрачная плоскость или сетка рядом с роботом |

Для лидарного или дальномерного датчика можно использовать `Proximity sensor` или `Vision sensor`, если требуется физическая имитация измерений. Для академической демонстрации ВКР достаточно показать расположение сенсоров и описать, какие данные они предоставляют алгоритму навигации.

## 4. Препятствия, старт и цель

1. Добавьте статические препятствия (`Add > Primitive shape > Cuboid/Cylinder`) и назовите их `obstacle_1`, `obstacle_2`, `obstacle_3`.
2. Расположите препятствия так, чтобы между стартом и целью существовал обходной маршрут.
3. Добавьте стартовую точку в виде небольшого зеленого диска или куба и назовите ее `start_point`.
4. Добавьте целевую точку в виде красного диска или куба и назовите ее `goal_point`.
5. При необходимости добавьте линию или набор маленьких сфер `path_point_1`, `path_point_2`, ..., чтобы визуально показать маршрут A*.

## 5. Сохранение и запуск

1. Сохраните сцену, например как `coppeliasim_robot_navigation_demo.ttt`.
2. Запустите симуляцию кнопкой `Start simulation`.
3. Из корня репозитория выполните:

```bash
python coppeliasim/coppelia_controller.py
```

4. Если CoppeliaSim или `zmqRemoteApi` не найдены, контроллер перейдет в fallback-режим, выведет понятное сообщение и сохранит демонстрационные метрики в `results/coppelia_metrics.txt`.

## 6. Что должно быть видно на итоговом скриншоте

- мобильный робот с корпусом, колесной базой и приводными колесами;
- сенсорные компоненты локального восприятия: лидар/дальномер, датчики расстояния, IMU, энкодеры и контактный сенсор;
- локальная карта или условная occupancy grid;
- статические препятствия;
- стартовая и целевая точки;
- траектория движения или набор точек маршрута.
# Настройка сцены CoppeliaSim

## Пошаговая инструкция
1. Откройте CoppeliaSim.
2. Добавьте модель PioneerP3DX.
3. Переименуйте главный объект модели в `robot`.
4. Нажмите Play.
5. Запустите из Windows CMD:

```cmd
python coppeliasim\coppelia_controller.py
```

## Проверка
- На сцене должны появиться красные препятствия, зелёные точки маршрута и синее динамическое препятствие.
- Робот `/robot` должен быть виден на полу и плавно двигаться по маршруту.
- Метрики сохраняются в `results/coppelia_metrics.txt`.

## Рекомендация для записи видео
- Используйте формат MP4/MPEG-4 part 2 или AVI/MPEG-4 part 2.

- Перед повторным запуском желательно остановить симуляцию и нажать Play заново.
